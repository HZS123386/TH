# 落地页报告四问改版

免费报告按「我是谁、我处在什么环境、环境如何影响我、近期何时值得关注」组织。前三部分分别解释性格与可调整之处、出生资料提示的环境倾向，以及一个有利因素和一个需要留意的因素；近期部分展示一个有计算依据的主题与观察时段。每条结论可展开核对依据。

免费部分还先提供一条简短的事业应对建议，并展示一个与付费事业章节共用计算依据的关键时段；其余领域的时段和完整行动步骤继续在付费报告中展示。

付费入口展示「关键时段、分析依据、应对建议」以及本命、事业、财运、感情、风险、行动六类内容，并使用原有主题图卡。按钮恢复为「支付并解锁」。手机号建单、官方收银台、到账核对和解锁权限继续沿用现有链路。

## 生成与快照

- `RoxyAstrology` 复用现有传输、限额和缓存，请求官方 `/forecast/transits`。参数与响应结构依据 [Roxy Forecast 文档](https://roxyapi.com/docs/guides/forecast) 和官方 OpenAPI 核对。
- 新报告增加一次最多未来 90 天的行运计算，放在已有后台预览生成任务内，不阻塞返回报告编号。结果与报告一起保存；付费生成复用该快照。
- 服务端校验出生资料、日期范围、UTC 时点、数量与有限数值。个人时段仅选取有本命目标的已验证相位，不把一般背景事件直接当成个人预测。
- 七天区间是包含该盘面时点的观察窗口，不代表某种影响必然持续七天。精确时点和区间由服务端填入，模型只解释主题及应对方法，不能编造日期或事件概率。
- 出生时间未知不请求个人时段；请求失败或没有可展示事件时明确说明，不补写预测。失败状态也保存在这份快照中，重试写作不会修改已保存的计算数据。
- 写作版本更新为 `western-four-questions-3`，同一天的相同提交保持去重。历史报告编号和内容继续保留，重新测算才生成新版内容。

## 数据与显示

现有 `summary + traits` 保留，预览新增 `environment / favorable / unfavorable / recent / response`。四问入口要求环境、利好、不利及一条事业建议完整；有有效时段时才允许 `recent`，且必须引用对应依据。免费写作上下文仅保留事业章节的一个时段，`response` 使用事业本命依据，完整步骤不会提前生成。付费主题的摘要和两项行动在存在时段时引用相应的计算结果。

免费接口只返回选中的概要与时间范围状态；章节、完整行动计划仍受服务端付款权限控制。Flutter 页面、九种语言文案、生成进度与 HTML/PDF 导出同步更新。旧快照缺少新字段时显示说明，不把旧段落伪装成新的环境或趋势结论。

## 验证

- 四问改版基线的后端全量测试：528 项通过。追加免费试读与恢复按钮后，相关后端回归 62 项、支付回归 93 项通过，包含非法日期、错误出生资料、未知时间、缺少时段、伪造依据、事业时段一致性与付费数据隔离。
- Flutter H5 全量测试：87 项通过，包含中、泰、英四问显示及付款入口无越权行为。
- TypeScript/Vitest：54 项通过，覆盖新版导出与付费内容隔离。
- 本地 Flutter 发布构建通过。独立浏览器上下文使用拦截的合成测试数据检查了四问、六类图卡和手机号窗口；未调用真实写作/Roxy 服务、未创建支付订单或付款。
