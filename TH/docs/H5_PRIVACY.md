| 报告 | 主库保存资料与正文；浏览器随机凭证控制访问 | 不将哈希/随机标识写成彻底匿名 |
| 删除 | 删除主报告和关联测试支付记录；生成中可能暂拒绝 | 不承诺同时清除所有统计、缓存、供应商记录和备份 |

| 用量、日志、备份 | 用量表无统一自动过期；访问日志按容量；备份周期未确认 | 不编造固定天数、即时全量删除或静态加密 |
| 统计 | 第一方来源、访问及报告转化；响应 DNT/GPC；非完整匿名 | 解释范围及异议渠道，不当作跨站广告 SDK |
| 测试 | 当前 H5 不真实收款；下载按钮只显示测试弹窗 | 不披露尚未启用的支付商为现有接收者 |

## 正式发布前尚需落实的事项

1. **接收请求的能力及当地代表。** 身份、地址、邮箱和泰国主要市场已经用户确认；仍应落实邮箱值守及处理请求的人，确认是否依法需要泰国代表或数据保护官，并核对北京主体的登记和授权。不能仅用 FATE 品牌名替代控制者身份。
2. **收集时告知及适用法律依据。** 现行表单按用户要求没有资料说明或同意弹窗。需要由运营方确认当前入口是否已满足收集前/收集时的显著告知；页脚链接和完整政策本身不当然满足所有场景。按实际用途确认服务必要性、合法利益评估，或需要同意的环节；不得事后把浏览或生成动作记录为一揽子同意。
3. **受托处理及跨境。** 核实与腾讯云、RoxyAPI、阿里云的合同主体、委托处理条款、接收地、后续处理者，以及泰国 PDPA 第 28/29 条及适用规则下的实际传输机制。Roxy 公布的 DPA 或 GDPR 表述不能自动替代泰国所需机制。尚无当前大陆端点零保留的核验记录。
4. **保留和完整删除流程。** 确定报告目的终止的标准、模型用量/安全记录最长必要期限、备份覆盖周期及责任人。确认已删除报告的关联统计和缓存如何处置、恢复备份时如何重放删除；若采用自动保留期限，先形成业务决定，再实现并测试，不能为了政策擅自删除已有报告。
5. **敏感文本及未成年人。** 自由文本会进入生成流程，当前没有独立敏感数据明确同意或监护人验证流程。确定服务年龄范围、必要保护及敏感数据处理规则，不能用政策里的“请勿提交”代替法定处理条件。中国法适用时，还需核对不满十四周岁未成年人信息的敏感信息保护、监护人同意及专门规则，不能用泰国的年龄说明替代。
6. **请求与事件响应。** 以最少信息核验报告控制权，落实访问/副本适用的 30 天期限及其他权利的各自期限。制定泄露发现、风险判断、记录和通知程序；72 小时规则有适用条件，不是对所有事件不分情况统一处理。
7. **语言及地区审阅。** 泰国用户应能得到清楚的泰文版本。正式发布前由运营方确认泰文法律用语及译文一致性。主体改为北京公司后，对中国境内开展的个人信息处理活动需同时核对中国《个人信息保护法》等适用义务，不能等到开放中国用户市场才评估。香港服务器与北京运营方属于不同概念，政策分别说明；其他市场正式开放前再作相应适配。

发布时还应核对服务器实际供应商、地域和功能开关与本地稿一致，尤其是 `LIFE_ASTROLOGY_PROVIDER` 对应 Roxy、Qwen 使用地域及真实支付是否启用。若线上仍使用旧排盘/旧配置，不应只发布新政策而保留不一致的数据流。

## 核对依据（2026-11-13）

- [阿里云百炼隐私说明](https://help.aliyun.com/zh/model-studio/privacy-notice)。不用于模型训练不等于零保留，不套用其他地域/套餐的零保留承诺。
- [腾讯云隐私说明](https://www.tencentcloud.com/document/product/301/17345)。基础设施处理客户内容与腾讯云自有账号/管理信息的角色不同。

- [中国《个人信息保护法》](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)、[国家网信办数据出境政策问答](https://www.cac.gov.cn/2026-07/24/c_1786638883119336.htm)。当前北京运营方对应中国境内处理义务与跨境路径需一同核对；不将泰国合法利益依据直接套用为中国法依据。本地政策审阅版本更新为 1.1。
