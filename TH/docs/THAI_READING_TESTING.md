# 泰式占星主题测算页

页面为 `/thai-test`，旧 `/bazi-test` 链接也显示此页。右上角菜单及“我的”提供“泰式占星解读”。原八字与Roxy工具保留在 `/tools/bazi`，两种计算分开使用。

## 计算与解读

`POST /api/thai-reading` 接收本次出生资料、`reading` 与 `year`，不修改账号或访客的出生档案。支持 `overview`、`annual`、`money`、`love`、`work`、`family`。

使用固定版本 `thai-astrology@0.3.2` 的 Suriyayatra 引擎，复用现有出生时间、IANA 时区、出生地点及固定 Anto 上升／整宫口径。日期、真实时间与可识别地点不足时停止解读，不填默认时辰或编造宫位。

各主题选取不同的实际宫位及其宫主星、宫主所在宫、占位星体与个人星位。事业重点为第十、六、三、十一宫；财富为第二、十一、八、五宫；感情为第七、五、一、四宫；家庭为第四、二、三、九宫。模型收到这些计算事实及主题，不收到姓名、原始出生日期、出生城市或聊天记录。

全年主题按所选公历年逐日计算曼谷正午行运，相对于实际本命上升计算宫位，并按月汇总。当前报告引用太阳、木星与土星的月度取样解释年度安排。取样不是精确入宫时刻，也不是事件发生概率；此流程不提供具体事件日期。

写作沿用服务端 `FORTUNE_PROVIDER`，复用已有提供商密钥，无需额外配置Roxy。配置缺失、额度不足或生成失败时保留真实排盘，显示对应状态，不替换成伪造的成功解读。服务复用已有有界流式写作、SQLite缓存和租约；`BAZI_REPORTS_PER_MINUTE`／`BAZI_REPORTS_PER_DAY` 设置为0表示不限本地生成次数，当前测试配置均为0。不同主题、语言、年份、出生资料及提示版本分别缓存。

人生报告 `life-report-2` 的基础信息、报告摘要和个人特点为免费内容，付费部分为事业发展、财务方面、感情与家庭、近期关注、总结建议。试读成功后，后台生成事业、财务、关系、家庭及年度参考的五份主题正文和总结建议，页面合并关系与家庭。新报告使用直接、较充分的自然段讲工作风格、发展建议等实际主题，不显示通用的问题式栏目名；仍严格校验结构、语言和引用，不以编造经历或夸赞来制造准确感。新资料请求不复用旧提示版本，历史正文按原快照保存。

解锁只开放已保存内容，失败时可继续生成。未解锁的接口响应和网页／PDF 导出不包含完整正文。浏览器 PDF 使用同一份经过权限筛选的报告内容及嵌入中文、泰文字体，不调用写作模型。跨主题仅复用试读文字，不传递试读引用编号；校验反馈会列出全部错误字段和未知编号。已保存总结建议的行动引用从原始主题记录解析，避免目录调整后丢失行动。

人生报告最多并行生成三个主题，同时服从已有全局模型并发限制；每个主题完成后立即保存，一项失败不阻断其他主题，全部主题齐备后才生成总结建议。重试只补缺失主题；任务心跳维持租约，避免排队或纠错期间被误判为停止。中文／泰文正文允许 APP、AA制、Excel 等常用表达，普通次数、步骤和规划时长不会触发计算值检查；“自己未……”也不会误判为干支。仍检查语言主体、内容完整性、真实引用和具体预测日期。Qwen3.7-Plus 使用现有 Pydantic 模型生成 JSON Schema 约束，减少遗漏字段和无效引用编号引发的重写；其他提供商保留原有 JSON 模式。页面暂停提示不再声称后台仍在生成。

实际模型请求用量写入本机 SQLite 的 `report_model_usage` 表，按报告编号区分 `preview`（免费试读）和 `full`（完整内容生成）。`full` 阶段可以在用户阅读试读时发生；若完整内容已生成，点击解锁不会新增模型调用。记录模型、输入／输出及缓存命中 Token；正文校验失败后的修复请求也计入。命中已有报告缓存不会新增模型调用。未收到服务商用量时通过 `usage_received=0` 明确标记，不能将其当作真实零消耗。日志不保存提示正文、出生资料或密钥。费用需在核算时按模型及当时单价另算，不写死到页面。

普通用户版报告从一句“先看结论”开始，接着用两个带短标题的说明点、三个详细提醒、四个行动方案解释所选问题。每个提醒包含适用情形、两个可观察信号、应对方式和生活例子；每个行动方案包含适用情形、四个具体步骤、例子、常见误区和检查方法。各字段使用短句，不靠重复或未经支持的断言增加篇幅。真实星体、星座、宫位及引用留在内部计算和校验中，不作为正文前缀显示；网页和导出也不展示上升、太阳、月亮的数据卡。

四语言校验覆盖摘要、标题、正文和全部扩展字段，拦截未知引用、重复内容、混合语言、过长内容、抽象术语以及模型自行补写的星体、宫位、数字和日期。每点必须引用所选主题的证据；年度每点保留月度和本命引用，并覆盖实际年份的前段、中段、后段。代码仅将实际引用的年份和月份输出为易读标签，各语言均使用所选公历年。没有原始响应、数据源选择或计算依据入口。缓存标识随新结构更新，重新生成后不复用旧短报告。

## 页面操作

1. 填写生日、准确出生时间、出生城市和出生地时区。不确定时间时保留未知状态，完整本命解读暂不可生成。
2. 常用城市可从滚轮选择；其他地点可展开地点目录或填写真实经纬度。目录选择会同步当地时区。
3. 选择六个主题之一；全年运势额外选择年份。
4. 生成个人报告后，清楚显示到“需要留意的地方”标题，标题下的提醒与后续行动方案全部虚化，中央显示锁图标。底部导航上方的“查看全部内容，请解锁”按钮复用现有固定动作区，点击即直接展开并定位到详细提醒，不跳转支付或创建订单。
5. 修改资料、主题、语言或重新生成会清除旧报告并恢复锁定；离开页面会移除解锁按钮。
6. 未解锁时“保存试读”仅导出结论、前面可读解读、“需要留意的地方”标题及锁定提示，不包含详细提醒与后续行动方案。解锁后“保存报告”包含完整内容。HTML均可打印为PDF，不含专业排盘段落、原始JSON或服务端密钥。

## 自动验证

```powershell
pnpm test
node scripts/python.mjs -m pytest backend/tests -q
pnpm exec playwright test e2e/thai-reading.spec.ts e2e/bazi-test.spec.ts
pnpm build
```

浏览器测试用独立数据库和关闭商业密钥的测试服务，验证实际本命计算、输入流程、旧链接、多语言、手机尺寸、导出及八字工具回归；涉及写作展示的浏览器样例明确为测试拦截数据。

开发服务启动并配置真实写作提供商后，可执行真实接口验收：

```powershell
node scripts/python.mjs scripts/verify-thai-reading.py --quick
node scripts/python.mjs scripts/verify-thai-reading.py
```

完整验收使用十组人工合成输入，覆盖六个中文主题、英语／泰语／越南语事业解读，以及不同出生时间的事业解读。结果留在忽略目录 `data/thai-evals/`，验证真实计算接线、生成状态、内容语言与报告段落。它不把程序一致性当作事件预测准确率，也不能替代同流派占星师及母语审读者的内容审评。
