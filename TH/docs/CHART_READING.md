# 星盘的全部解读入口

2026-11-06。个人星盘页新增“全部解读”，固定在底部五栏导航上方，沿用米白、砖红与古金主题。按钮与导航在同一固定容器中；ResizeObserver测量容器高度，给正文保留相应空间。适应不同语言、屏幕宽度、大字号与设备底部安全区域。

点击打开独立路由 `/chart/reading`，刷新保留页面，浏览器返回和页内返回均可回到个人盘，底部“我的星盘”保持选中。示例盘不显示个人解读入口，避免将示例资料当成用户档案。

解读页面读取 App 已加载的同一份泰式本命数据，不新增模型调用。显示本次生辰、太阳／月亮／上升、全部星体的位置与基础象征、十二宫及其宫主和落入的星体、实际星座关系连线。星体、星座、度数、宫位与连线直接来自现有引擎。段落为四语言的版本化基础符号说明，不是新生成的个性化AI长篇报告，也不声称已验证事件预测准确率。

十二宫术语对照 [Tandhava 的泰式宫位说明](https://tandhava.in.th/index.php/house-definition/) 做简短改写，保留实际计算的泰文宫名。尤其第六宫อริ涉及阻力与竞争，第十一宫ลาภะ涉及所得与支持，第十二宫วินาศ涉及损耗、隐秘与退省；不将这些名称转成确定的疾病、灾祸或收益预测。宫主与占位仍以项目实际采用的流派计算为准。

出生时间或地点不足时显示补充资料入口，不编造上升、星体及本命宫。修改生日／档案后页面读取新命盘。继续交流可使用现有“聊聊”流程；当日／周／月另到运势页查看，避免混淆出生时的位置和当前行运。
