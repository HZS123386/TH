# WANJAI 本地项目迁移说明

日期：2026 年 11 月 5 日。

后续泰式引擎接入已覆盖本文初版的太阳档案／固定教学盘方案，当前以 [GITHUB_INTEGRATION.md](GITHUB_INTEGRATION.md) 为准：个人泰式盘、分盘、ทักษา、泰历与行运已实接。首页三周期已改为实际行运加公开规则解读，规则见 [FORTUNE_RULES.md](FORTUNE_RULES.md)；长篇报告、今日陪伴和七步路径正文仍为编辑建议。

参考材料为用户提供的 `WANJAI-双击打开.html` 与 `WANJAI-1.0可行性与验证报告.html`。HTML 中的研究结论与上线清单作为设计材料处理，没有执行其中描述的外部业务操作。

## 体验与布局

主界面采用参考中的米白底、砖红按钮、黄铜金和鼠尾草绿、细边框和较轻的卡片。桌面保留左侧导航并提供内容侧栏；手机使用“运势、星盘、聊聊、好物、我的”五栏底部导航。泰语字体随应用本地打包，图案、星轮、商品示意均为本地 SVG，没有远程图片依赖。

当前首次流程为“确认四语言之一 → 填写生日 → 免费今日/本周/本月”，时间与城市选填。语言弹窗使用米白、砖红、古金主题与原生 dialog 焦点管理；按视口高度缩小间距和装饰，极短横屏使用双列，四选项和确认按钮无需内部横纵滚动。确认后记住语言，“我的”中可重开，取消恢复原语言。访客生日保存在本浏览器；登录没有档案的账号后预填，由用户确认绑定；已有账号直接恢复原资料。

## 数据与模块

`src/components/wanjai/` 按首页、问题、陪伴、报告、好物和我的拆分组件；`src/data/wanjai-*.json` 保存四语言内容。中文与泰语以参考内容为基础，英语、越南语补齐相同功能的编辑内容。页面用 React 文本渲染，没有执行离线版的 HTML 字符串渲染脚本。

`GET /api/companion`、`PUT /api/companion` 使用现有会话鉴权，保存所选问题与情况、行动标记、陪伴记录、收藏、心愿、阅读与回访偏好、模拟解锁标记。服务端限制字段、长度、记录日期和次数，并拒绝客户端指定其他用户。选择语言继续用独立偏好接口，不增加命盘版本或清空历史。

访客偏好保存在当前浏览器，不自动合并到任何账号。已登录数据保存到 SQLite 的 `companion` 表，退出前等待保存队列完成；保存请求捕获原会话，避免排队写入使用下一账号的令牌。聊天草稿只存在当前浏览器的 sessionStorage，并按内部账号 ID 分隔。现有数据库、账号、会话键与出生档案无需搬迁。

## 真实服务边界

- 模拟解锁标记不是支付权益。没有真实扣款、支付订单、退款或交易通知。
- LINE 登录、OA 推送、真正订阅状态、真人排期、商品库存和履约没有接入；本地设置不会实际发送消息。
- 没有完整西洋星历引擎、真实个人上升／月亮／宫位／行运计算，也没有泰式占星引擎。教学盘始终与个人生日独立。
- 可行性报告中的流量、获客和付费假设未变为真实业绩指标。原报告可在“我的 → 关于本地版本”中打开，并标注为中文报告。
- 真实模型按原有环境变量配置；本次浏览器测试使用演示助手，没有产生模型调用费用。

验证结果见 `VALIDATION.md`。
