## 图形

四角星与衬线大写字标延续落地页的品牌表达。主背景为 `#130c24`，桌面外框为 `#0b0715`，卡片为 `#20152f`，强调卡片为 `#27173d`，暖金为 `#e4bc78`，主文字为 `#fff5df`，次要文字为 `#b4a8c6`。这些色值取自已接入的落地页构建文件。

## 实现

- `src/lib/brand.ts` 保存统一矢量路径，供 React、SVG 导出和 Canvas 分享卡共用。
- `BrandMark.tsx` 渲染标志；`BrandLockup.tsx` 处理字标、大小和副标题。
- 四语言 JSON 的 `brandName/brandTagline/brandDescription` 等字段由既有 i18next 全局切换。
- 手机页头、首次语言选择、页面眉题、聊天署名、消息预览、个人页面、页脚、分享卡、浏览器标题和 description 使用统一品牌。
- 浏览器图标使用金色四角星，使用版本化 URL 避免旧图缓存。
- 排盘规则 ID、数据库、会话键、历史记录及原始可行性材料保留原技术标识，不对已有用户资料做改名迁移。
- 系统提示中的品牌名统一为 ASTRO · AI；原有聊天历史不重写。

## 矢量资产

运行 `pnpm build:brand`，生成 `public/brand/astro-star.svg`、浅色版及四份 `brand-{locale}.svg`，并更新 favicon。脚本使用项目已有 Node 类型擦除能力。

正式使用的 React 标志与导出资产均来自同一组路径。图标为代码原生 SVG，放大不失真；没有远程字体、图片或图标服务依赖。

参考 [RoxyAPI UI 文档](https://roxyapi.com/docs/ui) 的主题变量、图表放大和本地化展示方式，优化现有泰式星盘。保留现有泰式计算、宫位和星座关系来源，没有将泰式结果强行传给要求西洋本命数据的 Roxy 组件。轨道图标签跟随四语言；轨道图与传统盘均可放大查看，点选星体时继续使用本次计算数据展示详情。缺失出生时间或地点时继续显示资料不足状态。
