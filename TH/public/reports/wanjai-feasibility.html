Executive Summary｜给老板的结论

  • 值得先做免费体验验证；真实收费与放量须先通过业务准入。免费日周月内容、具体问题和陪聊可以组成入口；真正决定付费的是“理解我的处境，交付一份可以用的结果”。没有真实用户订单和留存数据，不能得出已经匹配市场或必然爆火。
  • 1.0 收窄为“一个问题 → 一次有用交流 → 一份明确交付 → 次日接着跟进”。首测以感情与工作两个场景获取样本，金钱与家庭保留；商店和真人咨询作为后续能力，不同时承担首轮收入目标。西洋占星是产品表达方式，需要验证泰国用户是否认同。
  • 先解决支付准入、泰语对话、内容更新和可信归因，再买流量。Omise和Stripe泰国对算命类有明确限制；Mini App数字商品支付范围也需LINE书面核实。LINE每日营销触达另需预算。模拟付款不能证明购买意愿。
  • 低客单价很容易买量亏损，首测只销售฿99专题方案。假设 1,000 个有效落地用户、600 人激活、30 人购买、双产品假设首单收入 ฿129、广告 ฿15,000，则获客成本 ฿500/付费者，扣除示例变动成本后双产品首单最多支持 ฿86.10。若首轮只卖฿99，同条件可承担CAC仅฿59.10。试投是购买证据，不能当作盈利预测。

03｜上线目标流程：每一步只给一个明确的下一步

以下是正式上线验收流程，不代表本地已全部接通；当前能力见第01节。首测收费只放฿99专题，฿199人生报告继续保留完整演示与试读，真实销售须完成个人排盘及交付验收。

  1. 广告：一个生活问题 + 一段真实产品输出。素材示例：“关系里难开口的话，先整理成一句”“想换工作，先理清下一步”。展示产品实际能力，不宣称知道观看者失恋、负债或必然转运。
  2. 落地：立即可看完整免费示例。提供生日入口自动匹配；无需先加好友、安装、付费或补齐出生时间。点问题只选中，主按钮统一推进，减少意外跳页。
  3. 首个价值：一屏读懂重点，然后进入聊聊。生日对应的基础说明 + 用户所选问题 + 一个行动。已选的情况随页面传递。不能把“个性化”写成收集更多表单。
  4. 互动：先回答，再问一个确实会改变建议的问题。提供直接可点的问法；自由输入能被理解；不重复要求生日或之前的选择。看完回答可选“有用 / 不贴近”。
  5. 付费：先看一段足够判断质量的完整试读。推荐一份与当前问题对应的产品，明示价格、内容、交付时间、客服和退款路径；99 与 199 是不同交付，不能用它们直接做价格 A/B。
  6. 履约：到账确认 → 可读报告 → 开始第一步。支付回跳失败仍可查单；重复点击不重复收费；已买内容可回看。真实付款成功以服务端回调验真为准。
  7. 回访：告诉用户明天回来接着看什么。首次获益后邀请订阅。默认保留每周选择，每日提醒由用户主动选；回流直达上次问题和当天更新，未读不催多次。
  8. 推荐：出现明确的“对我有用”后再邀请分享。用户选择可公开内容；分享卡不带生日、困扰、聊天和购买记录。朋友必须真实打开并完成首次价值，才记为有效推荐。

1.0 不把“强制关注 OA”放在免费体验之前。外部浏览器与 LINE 内打开都要有可用路径；登录、跨设备保存和消息订阅在用户理解收益后发生。当前本地版不产生真实广告点击、消息或交易。

05｜先算每位付费用户能承担多少获客费用

首单金额不能直接当 CAC 上限。费用要覆盖所有激活用户的免费使用成本，而不仅是购买者的生成费用。以下三组是决策测算，全部输入是假设，不是泰国行业均值、报价或实测业绩；后两组的混合产品收入仅用于后续双产品敏感性分析；首轮销售策略见表后说明。每组统一 1,000 个有效落地用户，七日内每位付费用户只买一单，复购和裂变收入按 0 计算。

统一成本假设：成功支付原始金额的 5% 作退款准备、5% 作支付费用，付费额外交付 ฿10/人；所有激活用户平均免费服务成本 ฿1/人。基准客单 ฿129 = 70%×฿99 + 30%×฿199；较强客单 ฿159 = 40%×฿99 + 60%×฿199。5% 支付费用不是“支付失败率”，失败支付已不计入购买人数。需用实际商户报价和真实用量替换。

可承担 CAC = 首单平均收入 × (1 − 退款比例 − 支付费率) − 付费额外交付成本 − 每激活用户免费服务成本 ÷ 激活到付款率
可承担落地成本 = 落地到激活率 × 激活到付款率 × 可承担 CAC

基准得出 ฿86.10/付费者、฿2.583/落地用户，明显低于假设的 ฿500 和 ฿15。即使页面转化不错，买量仍可能亏损。较强情景的正贡献仅 ฿1,232.50，尚未覆盖开发、人员、税费及 OA 套餐等固定成本，也不能据此宣称盈利。若该批服务还需独立承担Basic月费฿1,280，较强情景的正贡献也会转负。模型中的฿1为每激活用户的变动服务成本示例，OA基础套餐与其他固定费用在放量决策时另行扣除，避免漏算或重复计算。

敏感性：在基准 5% 付款率下，免费服务平均成本每增加 ฿1，可承担 CAC 就减少 ฿20。把免费聊做成无限额度之前，必须先测每个用户的成本、价值和滥用率。

06｜只用三项主指标决定是否继续

D1、D7、购买是从同一激活 cohort 观察的不同结果，不能继续串乘成“最后剩几人”。基准若实际观察到 30/600 付款，95% Wilson 区间约为 3.5%–7.0%；120/600 的 D7 区间约为 17.0%–23.4%。小样本支持方向判断，不能证明稳定胜出。

07｜按阶段释放预算，每一轮都有停止条件

建议先把真实闭环做小，再开两轮试投。准备期预估 2–4 周，受商户与 LINE 审核影响可能延长；这不是交付承诺。随后用 3–5 天做可用性，再 7 天封闭试用，14 天招募 + 至少 7 天等待最后一批 D7 成熟。各阶段可以部分衔接，退款与更长期复购继续观察。

08｜每日回访要有内容变化和问题进展

“每天发一句好运”不足以长期留住用户。首版同时准备公共内容日历与个人问题进展：公共层提供可阅读的日周月主题；个人层根据用户主动提供的情况和反馈接着走。用户休息、跳过或几天没来，记录保留，不用归零惩罚。

回访时点用户看见什么记录什么 / 下一次怎样变化
第0天：拿到首次价值一条结论 + 一件可执行的小事，任选感情/工作/钱/家庭保存选择与是否愿意继续，得到同意后保存记忆；不假设行动已完成
第1天：接上上次的事“昨天那一步，做起来怎样？”：有帮助 / 卡住 / 想休息有帮助推进；卡住换更小步骤并追问原因；休息降低强度
第2–6天：同一问题逐步展开一个新问题/行动模板，而非把昨天换一个幸运分数用已知事实与反馈生成下一步；每日内容按日期、主题、版本固定，避免刷新不断变卦
第7天：回顾过去哪些建议有用、哪些不贴近、下周继续哪件事展示真实记录计数；推荐另一份内容只能基于用户选择，不能制造危机推销

当前本地内容实际范围：28条生活小行动按曼谷星期每周循环，仅用于未选具体问题的已选主题用户；选定问题后使用固定情景路径，七步陪伴按反馈推进。日期变化不等于新的个人行运已生成。

正式首轮内容备货：28天×4主题=112条日卡、4周×4主题=16条周卡、1月×4主题=4条月卡；每条有标题、简短解读、行动、适用情况、有效日期、版本和泰语审校记录。再准备10问题×2情况的回答路径与20条追问。112/16/4 是制作验收清单，不能当作当前已上线的内容库存；本地可循环的编辑内容仅用于流程体验。

消息文案以用户选择的主题和进度为准，例如“你昨天选了先整理想说的话，今天可以继续第二步”。锁屏摘要避免透露敏感问题；未取得同意不发送，每日最多一次摘要是产品频控建议，另受 OA 额度和平台规则约束。

还要用真实样本回答的四个问题

  1. 用户愿意为“占星解释”付钱，还是更愿意为“具体问题的交流与行动方案”付钱？用不同价值主张引流、相同交付质量比较，不只问偏好。
  2. 用户认为内容“有用”后，是否愿意在没有优惠券的情况下付真实的99/199泰铢？观察真实订单，并访谈未购买者。
  3. 没有每日提醒时，仍有多少人主动回来？有提醒的人是读完就走，还是完成了下一步？分开看自然回访与提醒回访，随机实验只在同意接收的人群中做。
  4. 可持续的获客成本是多少？在真实成本下能否覆盖所有免费用户与客服？没有成熟复购数据前，不用假设LTV补平首单亏损。

结论边界与下一次决策

下一步可以批准“受控验证”，暂不批准“按爆款预期大规模投放”。先完成P0与真人任务测试，再释放第一轮广告预算；看到真实回访、真实付款、交付满意与成本同时过线后，才加预算。

本报告在2026年11月5日核验本地产品和可访问官方页面。商户准入、平台审核、费用与政策可能变动；官方文档冲突需书面澄清。财务情景全部是假设，目标线是本项目的试验规则，不是泰国市场基准。研究样本不能代表泰国所有人；占星内容属于文化体验与自我探索，不能替代事实或保证事件结果。

交互和内容可在离线文件体验；真实AI、支付、消息、库存、推荐归因与精确个人排盘不因页面完整而自动完成。
