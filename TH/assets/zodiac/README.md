# 十二星座图片

来源为用户提供的「十二星座_紫金能量环图标.zip」。`original/` 保留十二张原始 PNG，文件名统一为英文星座 ID；原文件名、字节数与 SHA-256 见 `manifest.json`。

网页使用 `public/images/zodiac/` 中的 96px 和 192px 透明 WebP，减少小图标加载量；图片内容、配色和比例沿用原图。`pnpm build:zodiac` 可使用本机 FFmpeg 重新生成，正常开发和生产构建直接使用已生成的文件，无需 FFmpeg。

`src/lib/zodiac.ts` 按白羊至双鱼的顺序建立 0–11 映射，与泰式引擎和四语言星座目录一致。运势页读取当前生辰计算返回的 `birth.reference_signs`，修改生辰后随计算结果更新；跨星座边界保留两张参考图片。不同生日若计算后仍属同一星座，继续使用该星座的图片。

现有个人星座图标、语言页装饰星座环及教学图形统一使用这组资源。泰式盘中的星座名称是文字标签，行星数字表示星体，它们继续保持原有含义与计算对应关系。
