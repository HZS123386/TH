Flutter 新增 `flutter_svg` 以直接显示原版 SVG 图标和徽章。人物、主题图、徽章、动画均取自 JY；品牌字样以原 CSS 字体渲染为透明图形，未打包系统字体文件。视频由 Flutter 的网页原生视频视图负责播放和 CSS 遮罩，替换了不能正确渲染渐隐边缘的通用播放器；预加载、暂停恢复、播放失败及停滞处理都在同一组件中完成。中泰文按钮沿用本地字体，并打包 SIL OFL 许可的 Noto Sans Symbols/2，以保证星芒及星座符号在弱网下完整显示，无须在线字体回退。参考 React 页面仅放在忽略的本地输出目录用于对照，没有接入产品入口。

有几处按真实服务保留：

- 数据仍使用本地泰式 Suriyayatra 引擎和原 AI 报告。界面中的排盘、隐私及时间精度说明据实填写，没有声称接入 Roxy 或改用西洋算法。
- 进度百分比继续读取实际生成内容；三阶段及结束动画遵循 JY 的呈现方式，没有用固定数值伪造生成进度。视频播放失败或停滞会退出，不阻塞结果。
- 出生时间未知时允许继续，明确提示按中午估算和可能偏差；星盘界面不将估算的上升、宫位当作确切结果展示。
- 页面保留 JY 的 ฿39 示例金额。测试阶段，付款与 APP 两个按钮均调用原报告解锁接口并生成完整内容；不会创建支付订单、扣款或跳转下载，首次资料提交仍只生成免费报告。完整生成继续使用实际进度、等待动画和本设备访问权限。
- 现有报告继续按原设备凭据和实际查看权限读取。没有套用 JY 独立工程的 24 小时失效规则；保留删除时的归属、运行任务及生成租约检查。

后端只在原报告响应中增加已计算星体位置的展示数据，不重复排盘、不新增模型请求，继续使用原报告鉴权。前端校验坐标及时间精度，旧报告响应没有星盘数据时可正常读取。已有完整报告的章节、行动计划、导出权限保持完整。

还补入了本地原有的四份 `TH/src/data/wanjai-*.json` 公共内容表。此前通用 `data/` 忽略规则会漏掉这些必要源码；现在仅为这些文件放行，运行数据库、用户数据、环境配置与密钥继续排除。

验证结果：Flutter 33 项、原 TypeScript 契约 27 项、后端全量 336 项通过；静态分析、类型检查及正式 Web 构建通过。390px 中文浏览器完整走通欢迎、表单、三阶段、真实进度、原生遮罩视频、解锁及已有完整报告；360px 泰语页面通过检查，没有脚本错误或外部字体请求。取消普通和分段视频请求后均能释放文件句柄，正式构建可在本地预览运行时正常替换。
