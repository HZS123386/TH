| JY 功能 | 合并方式 |
| --- | --- |
| 首次与再次访问欢迎页、上滑进入及人物过渡 | 使用现有 Flutter 路由和当前形象图实现；本标签会话进入后不重复拦截，保留表单状态；减少动态效果设置生效 |

| 生成资料摘要 | 在原生成弹窗展示日期、时间、地点和本次问题；继续使用后端实际内容进度 |
| 删除报告 | 从“我的报告”中确认删除；服务端校验原设备访问凭据并阻止删除正在生成的报告；同时清理测试支付引用 |
| 投放汇总 | 同源记录 `utm_source`、`utm_campaign`、访问、提交、报告展示；每个标签会话去重，结果需对应本会话已提交报告；浏览器 DNT/GPC 开启时不记录 |

统计不保存出生资料、问题正文、模型回答或原始 IP。只保存哈希后的现有设备身份、随机访问及报告编号和允许的渠道标签。查询只汇总最近 30 天；新访问时清理过期会话及关联。统计失败不阻塞报告。汇总命令在 TH 目录运行：

```powershell
python scripts/landing-metrics.py data/sabai.db --days 7
```
