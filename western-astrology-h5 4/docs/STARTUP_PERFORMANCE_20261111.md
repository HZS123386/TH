# 首屏加载优化

现场症状为公网 IP 页面长时间只有紫色背景。修改前直接测量公网资源：

- 完整中文 OTF 为 8,331,336 字节，未压缩，单次下载约 14.16 秒；主入口在绘制前等待此字体。
- 符号字体合计 915,008 字节，全部在初始化时加载。
- HTTP 环境没有 ImageDecoder，Flutter 会使用 skwasm_heavy；同一路径下，旧版无时限的图片预加载能阻止界面出现。限速复现超过 120 秒仍没有可操作的欢迎页，未发现脚本异常。

现在中文首次加载使用同一来源字体的精简 OTF，大小 347,812 字节。常用字库包含 GB2312 字符与公开地点名称所需字符，进入表单后预备；每次展示地点或完整报告前，按实际字符检查需要，缺字时再加载常用或完整字体。字体请求去重，失败可以重试。原完整字库和 PDF 字体仍保留。

符号字体按现有页面符号精简为合计 23,596 字节。衍生字体保留原轮廓及许可证并更名，构建时检查固定中文文案的覆盖范围。正常构建使用已提交的字体文件，无须安装字体工具；重新生成见 `scripts/fonts/README.md`。

首屏 HTML 提供加载状态，使用 Flutter 标准 bootstrap 回调更新阶段；由应用实际首帧绘制完成后移除，未使用虚构百分比。网络失败或过慢时提供重新加载。页面图片预加载最多等待 700ms，HTML 同时预加载欢迎和首页使用的图片，消除图片与首帧相互等待。

引擎资源地址包含 SDK revision，允许一年 immutable 缓存；业务入口和字体继续 no-cache 验证，报告接口仍为 no-store。保留 Flutter 标准 Wasm 和 JavaScript 两种构建。Python 服务为字体显式设置 MIME，从而让原网关 gzip/zstd 压缩正常生效。

验证记录位于忽略的 `output/startup-performance-20261111/`：

- Flutter 37 项测试及静态分析通过，后端相关 14 项测试通过。
- 同一 390×844、150ms 延迟、750,000 字节/秒下载限速、禁用 ImageDecoder 的环境：新版首次内容提示约 232ms，欢迎页可操作约 14,910ms；首屏没有请求常用或原完整中文字库。
- 该限速比较使用本地未压缩静态服务，不能当作用户公网实际耗时保证。公网已开启压缩；上线后的实际资源下载另行记录。
- Wasm 正常路径的资料、生成、视频、解锁和已有完整报告流程通过。
- JavaScript 兼容构建、图片请求不返回、字体请求失败后重试三个浏览器场景均通过。

先前的 flutter-first-frame 引擎事件可能出现在真正的应用界面之前；本轮改用应用首帧确认及可操作按钮测量，避免把紫色背景当成加载完成。
