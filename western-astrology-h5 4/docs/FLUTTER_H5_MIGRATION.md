# Flutter H5 迁移与验收记录

日期：2026-11-10。范围：本地 `western-astrology-h5 4` 落地页和报告页。公网服务器未发布本次更新，原 APP 工程未改动。

## 当前架构

页面入口为 `web-client/lib/main.dart`。落地页、出生资料、地点选择、报告、解锁弹窗、历史记录、状态管理和 API 调用均由 Flutter/Dart 实现。现有 Python 后端、泰式 Suriyayatra 计算、真实模型解读、SQLite 存储及设备报告凭据继续使用。

```text
Flutter Web 页面
  ├─ H5Controller：语言与本地字体
  ├─ ReportRepository：真实报告、地点、进度与取消
  ├─ LandingPage：出生资料、自定义问题、主题展示
  ├─ ReportPage / ReportViewModel：报告、目录、权限、反馈
  └─ CheckoutDialog / HistoryDialog：收银台与历史报告
          │
          ├─ /api → TH Python 后端 → 泰式计算 / 模型 / SQLite
          └─ 按需调用原 HTML / PDF 文档函数
```

PDF 文档工具保留为无界面的 JavaScript 模块，复用原有排版、嵌入字体和内容权限校验。页面不再挂载 React，也没有用 Flutter 套壳加载旧 React 页面。

## 实际发现并修正的问题

- 日期确认按钮误用报告完成文案；泰国地点搜索示例误显示中国地名。
- 小屏手机弹出键盘后，地区代表点说明挤占列表并造成溢出；已改为随列表滚动。
- 缓存报告已完成时，生成弹窗错过完成事件；根路由弹窗关闭和 Material 列表的显示问题。
- 重复点击生成或购买可能打开多层流程；已增加正在处理状态保护。
- 网页导出误用 PDF 状态提示；未完成报告的文件名可能显示 full；已对齐导出版本与权限。
- 泰文摘要缺少独立长度目标，容易被模型写成正文长度。现已把短摘要与正文分开约束，在 schema 中加入说明，并提供明确的过长字段改写反馈。
- 普通泰语词里的短字符片段被当成星座。例如“ความกระตือรือร้น”的片段会匹配“มกร”；已按完整词边界处理短星座名，仍拦截明确的星座、宫位等计算术语。
- Windows 临时文件占用可能使发布目录替换失败；构建现在对可恢复的占用短暂重试，保留上一版并在替换失败时回退。

## 首屏与刷新时间

测试环境为本机 Windows 的内嵌 Chromium 浏览器、Flutter release/Wasm 构建、localhost，无网络或 CPU 限速。浏览器进程已运行；“首次”指首次访问这个本地地址，并不等于全新设备或清空所有编译缓存。

首页取当前文档开始到 Flutter 首帧显示的时间，已包含字体和主图准备；报告取读取真实快照并显示正文后一帧的时间。此记录不是线上 LCP、弱网或 LINE 真机结果。

首页和中文报告按 360×800 视口检查。泰文报告的三次计时使用 1280×720 视口、内容最大宽度 450px。360px 的表单、日期选择、地区选择与键盘场景另有交互检查。两种语言的报告是同一个 report.html 路由；历史和收银台属于弹窗，没有独立的整页刷新 URL。

### 报告生成仍需改进

页面加载与新报告生成分开计算。真实泰文试读从提交到正文显示约 37.5 秒；完整正文是多次模型调用，耗时为分钟级。实测中模型仍可能输出过长段落，导致某个章节校验失败，需要继续生成。已验证重试仅补齐未完成章节，但本次没有把模型稳定性或完整生成速度认定为已达到正式付费发布标准。

没有用示例文字替代失败结果，也没有把生成进度提前设为 100%。测试使用独立 SQLite 数据库，未修改已有用户报告。
